Fixture data layout (built dynamically by kilo_test.go::setupKiloFixture):

  $TempDir/
    kilo.db    <- SQLite database; single `message` table with one row
                  whose `data` column carries the assistant message JSON

No binary fixture file is checked in — each test mints a DB via
sql.Open("sqlite", path) under t.TempDir() and disposes via cleanup.

Register the adapter via cmd/tm/cli/registry.go AllAdapters["kilo"].
Default lookup path: $HOME/.local/share/kilo/kilo.db.
Override: $KILO_DATA_DIR (comma-separated; each is a kilo root that
contributes its own <root>/kilo.db).
