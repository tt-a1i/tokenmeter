No binary fixture file is checked in — each test mints a DB via
sql.Open("sqlite", path) and disposes via t.TempDir() cleanup.

Register the adapter via cmd/tm/cli/registry.go AllAdapters["hermes"].
Lookup paths under default $HOME/.hermes/state.db; override via
$HERMES_HOME (comma-separated list).
