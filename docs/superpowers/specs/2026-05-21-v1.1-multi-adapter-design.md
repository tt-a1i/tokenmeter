# TokenMeter v1.1 — 多 Adapter 对齐 ccusage（设计稿）

**日期**：2026-05-21
**作者**：tt-a1i（决策） · Orchestrator（spec 整理）
**状态**：草稿，待 user 审阅 / 自动推进派工
**范围**：v1.1.0 一次性 ship 13 个新数据源 adapter，跟 ccusage feature parity

---

## 1. 背景

v1.0.x（已 ship 三个 minor）让 TokenMeter 在命令面、5h blocks、statusline、LiteLLM pricing、SQL push-down 性能上完全对齐 ccusage **核心 CLI**。但 ccusage 还支持 13 个 TokenMeter 没有的数据源（OpenCode / Amp / Gemini / Copilot / Goose / Codebuff / Hermes / Kilo / Kimi / Qwen / Droid / OpenClaw / pi-agent）。

v1.1 目标：**一次性 ship 全 13 个 adapter**，让 TokenMeter 在 source 覆盖上也达成 ccusage parity。

---

## 2. 决策记录（brainstorming 阶段 user 拍板）

| # | 决策 | User 选择 |
|---|---|---|
| V1 | 采集模式 | **batch-only**（每次 CLI 启动扫该 agent 日志，不进 daemon、不入 SQLite） |
| V2 | 命令面 | **ccusage 完全一致**（`tm <name> daily/weekly/monthly/session`，`tm daily` 无参 = all-source 合并 SQLite + 所有 batch scan） |
| V3 | 范围 / 节奏 | **v1.1.0 一次性 ship 全 13 个 adapter**（不分 wave） |
| V4 | Adapter 抽象 | **平铺式**，每个 collector 独立函数；不引入 Adapter trait（跟 ccusage 一致，因不同 agent 日志格式差异太大，trait 会成 leaky abstraction） |
| V5 | 测试 fixture | **从 ccusage 仓库借用** + 自补，每个 fixture 文件头标注 source attribution（ccusage MIT License） |
| V6 | daemon / SQLite schema | **完全不动**，v1.0 行为 100% 保留 |

## 3. 架构

### 3.1 数据流（v1.1 完成后）

```
Claude hooks ────→ tm emit ────→ Unix socket ──┐
                                                │
Codex JSONL ─────→ CodexWatcher ────→ daemon ──┤   实时（不变）
                                                │
Claude JSONL ────→ ClaudeLogWatcher ───────────┘
                                                │
                                                ▼
                          ~/.tokenmeter/data/tokenmeter.db (SQLite, 不变)
                                                │
                                                ▼ (CLI 直读)
                                          tm <subcommand>
                                                │
                ┌───────────────────────────────┼───────────────────────────────┐
                ▼                                                                ▼
        SQLite-backed sources                                          batch-only adapters (新)
        tm claude daily                                                tm amp daily        ──→ ~/.local/share/amp/threads/*.json
        tm codex daily                                                 tm opencode daily   ──→ ~/.local/share/opencode/...
                                                                       tm gemini daily     ──→ ~/.gemini/tmp/chats/*.{json,jsonl}
                                                                       tm goose daily      ──→ ~/.local/share/goose/sessions/<db>   (SQLite!)
                                                                       ... 13 个新 adapter
                                ┌───────────────┴───────────────┐
                                ▼                                ▼
                        tm daily（all-source）
                        = SQLite (Claude+Codex) + 扫所有 batch adapter（目录不存在 silently skip）
```

**保留**（v1.0 行为完全不变）：
- `internal/daemon/` / `internal/storage/` / `internal/event/` / `internal/web/` 任何代码不动
- `internal/collector/claude.go` / `codex.go` / `cost.go` / `pricing.go` 不动
- `internal/blocks/` / `internal/pricing/` / `internal/statusline/` 不动

**修改**：

- `cmd/tm/cli/aggregate.go` — `RunAggregate` 默认 all-source 时调度 batch scan + SQLite 合并；新增 `--no-scan` flag 让用户跳过 batch

**新增**：

## 4. Adapter 接口（平铺式，无 trait）

每个 collector 实现统一函数签名：

```go
// 在 internal/collector/<name>.go
package collector

import (
    "context"
    "time"
    "github.com/tt-a1i/tokenmeter/internal/event"
)

type AdapterOpts struct {
    Since    time.Time   // 零值 = 不过滤
    Until    time.Time
    Timezone string
    Project  string      // 多数 adapter 不支持，忽略即可
}

// LoadAmpEntries 扫 ~/.local/share/amp/threads/*.json，返回统一 UsageEntry 列表。
// 错误处理：
//   - 目录不存在 → return nil, nil（user 没装该 agent 是正常情况）
//   - 单文件 parse 失败 → log warning，跳过该文件，继续
//   - I/O 错误 → return err（上层决定是否中断）
// 环境变量：AMP_DATA_DIR 覆盖默认路径，逗号分隔多路径
func LoadAmpEntries(ctx context.Context, opts AdapterOpts) ([]event.UsageEntry, error) { ... }
```

13 个 collector 全部走相同模式：`Load<CamelName>Entries(ctx, opts)`。

**UsageEntry 类型**：实施时先 grep 项目找现有 unified type（很可能是 `storage.TokenUsageEntry`，v1.0.3 Task 1 已 export）。如果该类型缺 `Source string` / `ProjectPath string` 等字段，按需追加（schema 不变，仅 in-memory 字段）。如果项目没有 unified entry，在 `internal/event/usage.go` 新建 minimal type 给 collector 包用。**避免重复定义**——adapter 实施前先对齐类型。

## 5. CLI 命令面

### 5.1 命令树（新增的）

```
tm                            → tm daily 默认（v1.0 已是）
tm daily [--no-scan]          → all-source 合并；--no-scan = 仅 SQLite (Claude+Codex)
tm weekly / monthly / session → 同上 all-source 合并

tm claude daily/...           → 仅 SQLite Claude（v1.0 已有）
tm codex daily/...            → 仅 SQLite Codex（v1.0 已有）

# 新增 13 个 adapter 子命令（每个支持 daily/weekly/monthly/session）：
tm amp        daily/weekly/monthly/session
tm opencode   daily/weekly/monthly/session
tm gemini     daily/weekly/monthly/session
tm copilot    daily/weekly/monthly/session
tm goose      daily/weekly/monthly/session
tm codebuff   daily/weekly/monthly/session
tm hermes     daily/weekly/monthly/session
tm kilo       daily/weekly/monthly/session
tm kimi       daily/weekly/monthly/session
tm openclaw   daily/weekly/monthly/session
tm pi         daily/weekly/monthly/session
tm droid      daily/weekly/monthly/session
tm qwen       daily/weekly/monthly/session
```

### 5.2 Flag 兼容性

所有现有 flag 跨所有 source 工作：
- `--since YYYYMMDD / --until YYYYMMDD` — 适用全 source
- `--json` — 适用全 source（输出格式与 ccusage 兼容）
- `--breakdown` — 适用全 source（per-model 拆行）
- `--order asc|desc` — 适用全 source
- `--mode auto|calculate|display` — 适用 SQLite source；batch adapter 多数源 row 自带 cost，default `display`
- `--timezone IANA` — 适用全 source
- `--no-color` — 全局
- `--project <path>` — SQLite source 走 `sessions.cwd`；多数 batch adapter 不支持（忽略 + stderr warning）
- `--session-length` — 仅 `blocks` 用，不变

### 5.3 all-source 默认行为

`tm daily` 无 source 时：
1. 查 SQLite 拿 Claude + Codex 数据
2. 顺序扫 13 个 batch adapter 日志（目录不存在 → ENOENT 立刻 skip，无 IO 浪费）
3. 合并到 unified UsageEntry list → 按 bucket 聚合 → 输出

性能预期：用户机器只装 2-3 个 agent，其余目录 stat() ENOENT，扫总耗时 < 50ms。

`--no-scan` flag 跳过 batch 扫描，回归 v1.0 SQLite-only 行为（性能敏感场景或服务器无 agent 安装时用）。

## 6. 13 个 Adapter 数据源清单（ccusage 源码 ground truth）

| Source | 默认路径 | 格式 | env override | 难度 |
|---|---|---|---|---|
| **OpenCode** | `~/.local/share/opencode/` (sessions/projects 子结构) | JSON/JSONL | `OPENCODE_DATA_DIR` | M |
| **Amp** | `~/.local/share/amp/threads/*.json` | thread + `usageLedger.events[]` | `AMP_DATA_DIR` | M |
| **Gemini CLI** | `~/.gemini/tmp/chats/*.{json,jsonl}` | JSON/JSONL 混合 | `GEMINI_DATA_DIR` | M |
| **GitHub Copilot CLI** | `~/.copilot/otel/*.jsonl` | OpenTelemetry JSONL | `COPILOT_OTEL_FILE_EXPORTER_PATH` | M |
| **Goose** | `~/.local/share/goose/sessions/<db>` <br> 或 macOS: `~/Library/Application Support/goose/sessions/` | **SQLite DB** | `GOOSE_PATH_ROOT` | **H** |
| **Codebuff** | `~/.config/<channel>/projects/<project>/chats/<dir>/chat-messages.json` | JSON | `CODEBUFF_DATA_DIR` | M |
| **Hermes** | `~/.hermes/state.db` | **SQLite DB** | `HERMES_HOME` | **H** |
| **Kilo** | `~/.local/share/kilo/<db>` | **SQLite DB** | `KILO_DATA_DIR` | **H** |
| **Kimi** | `~/.kimi/sessions/<group>/<session>/wire.jsonl` | JSONL | `KIMI_DATA_DIR` | L |
| **OpenClaw** | `~/.openclaw/` 或 `~/.clawdbot/` / `~/.moltbot/` / `~/.moldbot/` | JSONL | `OPENCLAW_DIR` | L |
| **pi-agent** | `~/.pi/agent/sessions/<project>/agent_<id>.jsonl` 或 `prefix_<id>.jsonl` | JSONL（含 `input` / `output` / `cacheRead` / `cacheWrite` / `cost.total` 字段） | `PI_AGENT_DIR` | M |
| **Droid** | `~/.factory/sessions/*.settings.json` | JSON settings | `DROID_SESSIONS_DIR` | M |
| **Qwen** | `~/.qwen/projects/<project>/chats/*.jsonl` | JSONL | `QWEN_DATA_DIR` | M |

**难度说明**：
- L (Low) — JSONL/JSON 简单遍历，~0.4 天
- M (Medium) — 含特殊结构（如 amp 的 thread/ledger 双结构、copilot 的 OTEL schema、pi 的字段命名 quirk），~0.6 天
- **H (High)** — **SQLite DB source**，需要打开 DB + 读 schema + SQL 查询，~1 天

**总工作量估算**：3 H + 8 M + 2 L = 3×1 + 8×0.6 + 2×0.4 = **8.6 天纯实施**，两个 coder 并行 **4-5 天**。

**SQLite 源 schema 探查策略**：在实施每个 SQLite adapter 时，先读 ccusage 对应 .rs 文件的 SQL query 文本（ccusage 已经 reverse-engineer 过 schema），抄成 Go SQL，再写 fixture DB。

## 7. Adapter 实施模板

每个 adapter 的 commit 应包含三件套：

1. `internal/collector/<name>.go` — 含 `Load<Name>Entries` 函数 + 私有解析逻辑
2. `internal/collector/<name>_test.go` — fixture-driven 测试，覆盖：
   - 标准 happy path（fixture 含正常 token 字段）
   - 缺失目录 → return nil, nil
   - malformed file → skip + warning，不阻塞其他文件
   - cost 字段优先级（如果 fixture 自带 costUSD，display 模式使用；否则 calculate）
3. `internal/collector/<name>_fixtures/<filename>` — 1-3 个 sample，每个文件头有 attribution：
   ```
   # Fixture borrowed from ccusage v20 (MIT License)
   # https://github.com/ryoppippi/ccusage/tree/main/apps/ccusage/test
   ```

`cmd/tm/cli/router.go` Route() 加该 source 的 case：
```go
case "amp", "opencode", "gemini", "copilot", "goose", "codebuff",
     "hermes", "kilo", "kimi", "openclaw", "pi", "droid", "qwen":
    cmd.Name = "adapter"
    cmd.Source = name
    cmd.AggregateArgs = AggregateArgs{Shared: shared, Bucket: parseBucket(rest)}
```

`cmd/tm/cli/adapters.go` 路由：
```go
func RunAdapterCommand(ctx context.Context, w io.Writer, source string, args AggregateArgs) error {
    loader, err := buildAdapterLoader(source) // 返回包装好的 AggregateLoader
    if err != nil {
        return err
    }
    return RunAggregate(ctx, w, args, loader)
}

func buildAdapterLoader(source string) (AggregateLoader, error) {
    switch source {
    case "amp":     return adapterLoaderFromFn(collector.LoadAmpEntries), nil
    case "opencode": return adapterLoaderFromFn(collector.LoadOpenCodeEntries), nil
    // ... 13 个 case
    }
}
```

`adapterLoaderFromFn` 把 `func(ctx, opts) ([]UsageEntry, error)` 封装成实现 `AggregateLoader` interface 的 struct（in-memory 实现，不走 SQLite）。

## 8. all-source 合并实现

`RunAggregate` 默认（Shared.Source == "" && !Shared.NoScan）走 all-source 路径：

```go
func RunAggregateAllSource(ctx, w, args, sqliteLoader) error {
    entries, _ := sqliteLoader.ListUsageForBlocksFiltered(ctx, since, until, project)
    // 合并 batch adapter
    for _, source := range allBatchAdapters {
        adapterEntries, err := buildAdapterLoader(source).Load(ctx, opts)
        if errors.Is(err, fs.ErrNotExist) {
            continue // user 没装该 agent
        }
        if err != nil {
            log.Printf("warning: %s adapter failed: %v", source, err)
            continue
        }
        entries = append(entries, adapterEntries...)
    }
    return renderBucket(w, entries, args.Bucket, args.Shared)
}
```

**性能预期**：13 个 stat() 调用 + 已安装 agent 的实际扫描。目录不存在 case 总耗时 < 5ms（fast path）。

- happy path fixture → parse → 验证关键字段（model / input / output / cache / cost / timestamp）

- malformed JSON / JSONL line → skip + warning
- env override 路径生效（如 `AMP_DATA_DIR=/tmp/test`）

## 11. 风险与缓解

| 风险 | 级别 | 缓解 |
|---|---|---|
| 13 个 agent 日志格式不稳定（小众 agent 变格式不通知） | M | 单 adapter 失败 → stderr warning + skip，不阻塞其他 source 输出。覆盖 ccusage 对应 .rs 已知 quirk |
| SQLite DB source 跨平台路径不同（Goose macOS 路径特殊） | M | 每个 adapter 实现 try 多路径 + env override（ccusage 源码已 specify） |
| `tm daily` all-source 扫 13 目录耗时 | L | ENOENT fast path < 5ms；`--no-scan` 提供退路 |
| ccusage fixture 借用法律风险 | L | MIT License 允许，每个 fixture 加 attribution |
| 13 个 adapter 同时进 main 撞 commit/index race | M | 实施时按 v1.0 项目纪律 + 包内文件隔离（每个 adapter 独立 `<name>.go`，互不撞） |
| Adapter `--project` 语义不一（多数不支持） | L | 不支持 → 忽略 + 一次 stderr warning，不报错 |

| Wave | Easy (L) | Medium (M) | Hard (H, SQLite) |
|---|---|---|---|
| Wave 1 | Kimi、OpenClaw | OpenCode、Amp、Gemini、Copilot | — |
| Wave 2 | — | Codebuff、pi-agent、Droid、Qwen | Goose、Hermes、Kilo |

- `cmd/tm/cli/adapter_integration_test.go` 集成测试
