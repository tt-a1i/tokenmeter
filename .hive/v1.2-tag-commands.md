# v1.2.0 Tag Commands

> Run these from the agmon repo root after release blockers are resolved.

## Pre-flight

```bash
# Confirm local main is current.
git fetch origin
git checkout main
git pull --ff-only origin main
git log -1 --oneline  # should be the final verified commit

# Confirm the working tree is clean except known local-only files.
git status --short  # should only show known .hive/ or local scratch files, if any
```

## Tag

```bash
git tag -a v1.2.0 -m "Release v1.2.0 — see CHANGELOG.md"
git push origin v1.2.0
```

## Post-flight

```bash
# Check that the tag-triggered release workflow started.
gh run list --workflow=CI --limit=5
gh run list --workflow=release.yml --limit=3 2>/dev/null || true
gh release view v1.2.0
```

## Rollback

```bash
# Use only if release CI fails and the tag must be re-issued after a fix.
git tag -d v1.2.0
git push origin :v1.2.0
# Fix the issue, then create and push the tag again.
```
